# MANIFEX-ART Scientific Intelligence — Doctrine

Governing principles for the independent scientific problem-solving system.
No source repository is modified by this project. Clones are read-only workshops.

## 1. Scope

This system solves mathematical, physical, and scientific problems. It does not govern, deploy, or extend the broader KCN ecosystem. Governance, deployment, and ecosystem integration are external concerns that may consume this system's outputs but do not live inside it.

## 2. Source Policy

Source repositories are read-only inputs for investigation. Mechanisms are studied, described in implementation-neutral terms, and independently reconstructed. Source code is not copied or rebranded. A capability register records repository, branch, file path, commit or blob SHA, retrieval date, license, observed mechanism, and reconstruction status for every borrowed idea.

## 3. Authority

Human authority is external to the system and expressed before any consequential operation. Capability discovery is informational; registration does not grant authority. The system stops on conflict between doctrine and operation.

## 4. Three Producers, One Ledger

Forward solving, backward solving, and bidirectional solving are three distinct producers. Each stamps every intermediate statement with an evidence class: OBSERVED, INFERRED, VERIFIED, or NOT_MEASURED. VERIFIED is reserved for the moment two chains connect and residual checks pass — the only place a theorem-class claim can be born.

## 5. Result States

Every solving attempt ends in one of: SOLVED_VERIFIED, CANDIDATE_FOUND, PARTIALLY_SOLVED, COUNTEREXAMPLE_FOUND, BLOCKED, UNRESOLVED. Missing measurement is NOT_MEASURED, never success.

## 6. Conflict as Data

When forward and backward derivations diverge, the contradiction is stored as structured data with both derivation paths attached. It is not discarded as an error. Divergences become the failure map — the research output of a dead end.

## 7. Generating, Checking, Proving

These are three different capabilities and must never be conflated. A generated candidate is not verification. A residual check is not a formal proof. A formal proof establishes only the formalized proposition under its stated assumptions. Numerical convergence is not experimental validation of a physical theory.

## 8. Hash Chaining Limits

Append-only hash-chained ledgers detect tampering in a record sequence. They do not prove authorship or truth.
